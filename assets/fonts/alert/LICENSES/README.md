# Fonts in assets/fonts/alert

Bitmap (BDF) fonts used by the alert and EEW screens. All are freely redistributable; credits:

- X11 misc-fixed (4x6 … 10x20), Helvetica-free classics: public domain / X11 licence.
- Spleen (Frederic Cambus, BSD-2), Terminus "t0" (Dimitar Zhekov, OFL), ProFont (MIT-style),
  Tamzen (Suraj N. Kurapati, based on Tamsyn — free), Gohufont (WTFPL), ctrld (MIT), Cherry (MIT),
  Dina (Jørgen Ibsen, free), Cozette (MIT), artwiz fonts (GPL/free), bitocra (free).
- Unscii (viznut, public domain) — converted losslessly from its .hex bitmaps to BDF.
- u8g2 bundle fonts (ArtosSans, Victoria, Torus, Chroma, squeezed, amstrad_cpc_extended, nokia-small):
  see https://github.com/olikraus/u8g2/wiki/fntlistall for each font's licence.
- Japanese: M+ Bitmap Fonts (M+ FONTS PROJECT, free licence) converted from JIS X 0208 to Unicode
  with Tamzen ASCII merged in (jp-mplus*); k8x12 and Misaki (門真 なむ / littlelimit.net — free,
  redistribution permitted; see misaki-k8x12-readme.txt / k8x12.txt).
